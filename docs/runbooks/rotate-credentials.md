### ทำไมถึงไม่มีใครรู้

- **ไม่มีการแจ้งเตือนใด ๆ** รู้เพราะบังเอิญไปอ่าน log ของ worker ในวันถัดมา

  `DATABASE_URL` และ import `psycopg` ได้ไหม ซึ่งจริงทั้งคู่แม้ฐานจะปฏิเสธรหัสผ่าน
  (แก้แล้วใน BACKLOG #97: ยิง `select 1` จริงและตอบ **503** เมื่อต่อไม่ได้)
- ผู้ใช้เห็นแค่ “เกิดข้อผิดพลาดภายในเซิร์ฟเวอร์” ซึ่งถูกต้องตามดีไซน์ แต่ไม่มีใครเห็น

### ลำดับที่ถูกต้อง — **Vercel ก่อนเสมอ เครื่องตัวเองทีหลัง**

1. รีเซ็ตรหัสที่ผู้ให้บริการ แล้ว **คัดลอกทันทีก่อนรีเฟรชหน้า** (Supabase โชว์ครั้งเดียว)
2. อัปเดต `DATABASE_URL` ที่ **Vercel** → Save → **Redeploy** (แก้ตัวแปรเฉย ๆ ไม่มีผล

4. **ค่อย**เอาค่าเดียวกันใส่ `.env` ของเครื่องตัวเอง

### ทางที่ดีกว่า — ไม่ต้องเอา `DATABASE_URL` มาเลย

ถ้าจุดประสงค์คือ **รัน migration** ให้ใช้ **SQL Editor ของ Supabase** วาง SQL ตรง ๆ
ไม่ต้องรู้รหัสผ่าน ไม่ต้องแตะ Vercel ไม่ต้อง redeploy ไม่มีช่วงที่ระบบล่ม
— ทำแบบนี้สำเร็จมาแล้วกับ #95 (เพิ่มคอลัมน์ `invites.max_uses` / `used_count`)

**บทเรียน**: ตั้งคำถามว่า “ต้องการ `DATABASE_URL` ไปทำอะไร” ก่อนเสมอ ถ้าคำตอบคือ
“รัน SQL ครั้งเดียว” แปลว่า**ไม่ต้องการมัน**

## ลำดับการหมุน

เรียงตามความเสียหายถ้าถูกใช้ก่อน · **`LLM_API_KEY` (ข้อ 5) เป็นตัวเดียวที่ยืนยันแล้วว่าหลุดจริงและยังหลุดอยู่** ถ้าจะทำทีละตัว ให้ทำตัวนั้นก่อนเลย ที่เหลือเป็นการหมุนเชิงป้องกันจากเหตุการณ์ที่ 1 และ 2

**1. `VERCEL_TOKEN`** — หมุนก่อนเพื่อน เพราะตัวนี้เป็นกุญแจไปสู่ตัวอื่นทั้งหมด (อ่าน env vars ของโปรเจกต์ได้)
Vercel → Account Settings → Tokens → เพิกถอนตัวเก่า สร้างใหม่ → อัปเดต `.env`

**2. `DATABASE_URL`** — Neon/Supabase → รีเซ็ตรหัสผ่านของ role หรือสร้าง role ใหม่
อัปเดตที่ **Vercel env vars** แล้ว **redeploy** จากนั้นอัปเดต `.env`
ตรวจว่าเว็บยังล็อกอินและเปิดรายการประชุมได้ ก่อนเพิกถอนของเก่า

**3. คีย์ R2** — Cloudflare → R2 → Manage API Tokens → สร้างใหม่แบบ **Object Read & Write จำกัดเฉพาะบัคเก็ตที่ใช้**

⚠️ ถ้าเพิกถอนก่อนทดสอบ ระบบอัปโหลดจะล่มทั้งตัว

**4. `WORKER_TOKEN`** — เป็นค่าที่คุณกำหนดเอง ตั้งใหม่ให้ตรงกันทั้งสองฝั่ง
Vercel env vars **และ** `.env` ของทุกเครื่อง worker (1346 และเครื่องอื่นถ้ามี) แล้วรีสตาร์ต worker
worker กับเซิร์ฟเวอร์ต้องตรงกัน ไม่งั้นงานจะค้างคิว

**5. `LLM_API_KEY` · `STT_API_KEY`** — หมุนที่ผู้ให้บริการ อัปเดต Vercel + `.env` + เครื่อง worker

## กันไม่ให้เกิดซ้ำ

- **อย่าคัดลอก `.env` ไปเครื่องที่ใช้ร่วมกับคนอื่นหรือกับ CI runner** ถ้าจำเป็นต้องรันคำสั่งที่ใช้ credential บนเครื่องอื่น ให้ป้อนเฉพาะค่าที่ต้องใช้ผ่าน `read -rs` (ไม่เข้า shell history ไม่เขียนลงดิสก์ หายไปเมื่อปิด session) แทนการยกไฟล์ไปทั้งไฟล์
- **แยกไฟล์ตามหน้าที่** — `.env` ของ worker ไม่ต้องมี `DATABASE_URL`, คีย์ R2 (`S3_*`) หรือ `VERCEL_TOKEN` เลย — ยืนยันจากโค้ดแล้วว่า worker รับ presigned URL จากเซิร์ฟเวอร์ ไม่ได้เซ็นคำขอเอง (`setup-worker.ps1` เขียนไว้ถูกแล้วว่า worker ไม่ต้องใช้) · ตรวจซ้ำได้ด้วย `tests/test_backlog_58_worker_needs_no_blob_keys.py`
- **แยก bucket และฐานข้อมูล dev ออกจาก production** เพื่อให้การทดสอบที่พลาดไม่แตะของจริง
- ทุกครั้งที่เปิดเซิร์ฟเวอร์ทดสอบ ให้ล้าง `S3_BUCKET S3_ENDPOINT S3_ACCESS_KEY_ID S3_SECRET_ACCESS_KEY` ก่อน (`tests/_harness.py` ล้างให้อัตโนมัติแล้ว)

### ต้องล้าง history ไหม

**เอกสารเดิมบอกว่าไม่ต้อง ซึ่งผิด** ตัดสินใจได้สองทาง:

1. **หมุน `LLM_API_KEY` อย่างเดียว ไม่ล้าง history** — ค่าที่หลุดกลายเป็นขยะทันทีที่หมุน
   ง่ายและไม่ทำลายอะไร แต่คีย์เก่ายังอ่านได้ตลอดไป และใครที่เก็บ clone ไว้ก่อนหน้าก็ยังมี
   **ทางนี้พอ ถ้าหมุนแล้วจริง**
2. **หมุนแล้วล้าง history ด้วย** (`git filter-repo` หรือ BFG) — ต้อง force-push ซึ่งเปลี่ยน
   hash ของทุกคอมมิตหลังจุดนั้น clone/fork/worktree ทุกตัวต้อง reset ใหม่ และ PR ที่เปิดค้าง
   จะพัง **ทำก็ต่อเมื่อหมุนแล้วและยังต้องการให้ repo สะอาดจริง ๆ**

ไม่ว่าเลือกทางไหน **ต้องหมุนก่อนเสมอ** — การล้าง history โดยไม่หมุน ไม่ได้ช่วยอะไรเลย

  ตรวจซ้ำเองได้ — คำสั่งนี้พิมพ์แค่ **ชื่อตัวแปร ความยาว และ sha256 12 ตัวแรก**
  ไม่มีค่าลับตัวไหนออกมา รันทั้งสองฝั่งแล้วเทียบบรรทัดต่อบรรทัด:

  ```bash
  # เครื่องเจ้าของ
  python - .env <<'PY'
  import hashlib, io, os, sys
  p = sys.argv[1]
  for raw in io.open(p, encoding='utf-8'):
      line = raw.strip()
      if not line or line.startswith('#') or '=' not in line: continue
      k, _, v = line.partition('=')
      v = v.strip().strip('"').strip("'")
      fp = hashlib.sha256(v.encode()).hexdigest()[:12] if v else 'EMPTY'
      print(k.strip(), len(v), fp, sep='\t')
  PY

  ssh aistudiofebc@ssh.appreview.cloud \
  ```
